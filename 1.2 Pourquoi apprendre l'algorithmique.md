# Introduction

Beaucoup de personnes pensent que programmer consiste simplement à apprendre un langage comme Python, JavaScript ou Java.

En réalité, un programmeur ne passe pas son temps à mémoriser des mots-clés.

Son véritable travail consiste à **résoudre des problèmes**.

Avant d'écrire une seule ligne de code, il doit réfléchir à la meilleure façon d'arriver au résultat souhaité.

Cette réflexion, c'est **l'algorithmique**.

> **À retenir**
>
> **Le code n'est que la traduction d'un algorithme dans un langage de programmation.**

# Programmer, c'est résoudre un problème

Lorsque tu crées un programme, ton premier objectif n'est pas d'écrire du code.

Tu dois d'abord comprendre le problème.

Prenons un exemple.

Tu souhaites créer une calculatrice.

Avant d'écrire le programme, tu dois répondre à plusieurs questions :

* Que doit saisir l'utilisateur ?
* Quelles opérations sont possibles ?
* Comment effectuer le calcul ?
* Comment afficher le résultat ?

Toutes ces questions sont résolues **avant même de choisir un langage de programmation**.

# Construire une maison

Construire un programme ressemble beaucoup à la construction d'une maison.

On ne commence pas par poser les briques.

On commence toujours par réaliser un plan.

Une fois le plan terminé, les ouvriers construisent la maison.

En programmation, c'est exactement la même chose.

* L'algorithme est le plan.
* Le langage de programmation permet de construire ce plan.

Sans plan, la construction devient difficile.

# Tous les langages utilisent la même logique

Prenons un problème très simple.

**Afficher un message de bienvenue.**

Peu importe le langage utilisé, l'idée reste identique :

1. Demander le nom.
2. Lire le nom.
3. Afficher un message de bienvenue.

L'algorithme ne change pas.

Seule l'écriture du code est différente.

# Exemple

nom = input("Votre nom : ")

### JavaScript

```javascript
const nom = prompt("Votre nom");
console.log("Bonjour " + nom);
```

Même logique.

Deux écritures différentes.

# Pourquoi apprendre les algorithmes avant un langage ?

Lorsque tu comprends les algorithmes, tu peux apprendre un nouveau langage beaucoup plus rapidement.

Tu n'as plus besoin de réfléchir au problème.

Tu dois seulement apprendre la manière dont le langage écrit les instructions.

Autrement dit :

> **L'algorithmique est une compétence que tu conserveras toute ta vie, même si tu changes de langage.**

L'algorithmique permet de :

* organiser ses idées ;

* écrire des programmes plus clairs ;
* trouver les erreurs plus rapidement ;
* créer des applications plus fiables ;
* apprendre de nouveaux langages plus facilement.

# Tranzisyon pou pwochen leson an

Kounye a ou konprann poukisa algoritmik enpòtan anpil anvan ou aprann yon langaj pwogramasyon.

Nan pwochen leson an, ou pral dekouvri **kijan pou ekri yon algoritm an pseudo-kòd**, yon fason ki senp, klè epi inivèsèl pou dekri yon solisyon anvan ou pase nan ekriti kòd la.
